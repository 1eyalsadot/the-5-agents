# convention: .gitkeep

**שייך ל:** תשתית (Git)

## מה זה
`.gitkeep` הוא קובץ ריק בלי משמעות מיוחדת ל-Git עצמו. הוא קונבנציה: מכניסים אותו לתיקייה שאחרת הייתה ריקה, כדי ש-Git יעקוב אחריה (Git לא שומר תיקיות ריקות). כשהתיקייה מתמלאת בקבצים אמיתיים, ה-`.gitkeep` נשאר אך מאבד את תפקידו.
