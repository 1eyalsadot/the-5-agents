## מה הקובץ עושה
מגדיר את **פרוטוקול הכספת** (`vault/`) כזיכרון ארוך-טווח של הפרויקט. עיקרון: קובץ אחד לכל נושא, עם Overview + Open Questions + Session Log מתוארך.
- **Phase 1 (לפני משימה):** איתור קובץ הנושא, קריאה מלאה, קריאת Meeting Notes אחרונים.
- **Phase 2 (אחרי משימה):** עדכון Overview, הוספת entry מתוארך עם status tag ו-`[[wikilinks]]`, אימות בקריאה חוזרת.
- תיקיות: `Meeting Notes/`, `Content Briefs/`, `Publishing Log/`, `Brand Guidelines/` — כל אחת עם `_index.md`.
- הורד מה-repo `ZeremItay/the-5-agents-obsidian`.
