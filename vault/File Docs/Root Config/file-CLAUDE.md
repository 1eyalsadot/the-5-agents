## מה הקובץ עושה
קובץ ההוראות הראשי של הפרויקט — נטען אוטומטית לכל סשן. מגדיר את **ראובן**, המנכ"ל שמקבל בקשות מהמשתמש, מבין מה צריך, ומנתב את המשימה לסוכן הנכון. מכיל:
- תיאור הצוות (חן, יעל, יובל) ומילות ההפעלה (triggers) לכל סוכן.
- התהליך ליצירת תוכן חדש מהאינטרנט (חן → יעל → יובל).
- התהליך המלא למאמר עם תמונות (placeholders של `{{IMAGE_NEEDED}}` → יובל).
- מבנה התיקיות של הפרויקט.
