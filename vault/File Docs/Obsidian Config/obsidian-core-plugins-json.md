# .obsidian/core-plugins.json

**נתיב:** `.obsidian/core-plugins.json`
**שייך ל:** אפליקציית Obsidian

## מה הקובץ עושה
מגדיר אילו **תוספי ליבה** של Obsidian מופעלים. בין המופעלים הרלוונטיים לכספת: `graph`, `backlink`, `outgoing-link`, `properties`, `tag-pane`, `templates`, `sync`, וחשוב — `bases: true` (מאפשר קבצי `.base`, ראה [[skill-obsidian-bases]]).
