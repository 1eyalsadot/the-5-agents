# File Docs — מפת כל קבצי הפרויקט

תיעוד קובץ-אחר-קובץ של פרויקט **the 5 agents** (מערכת צוות סוכנים ליצירת תוכן, בניהול ראובן). כל קובץ בפרויקט מתועד בנוטה ייעודית: מה הוא עושה, למי הוא משויך, ואילו קבצים קשורים אליו (`[[wikilinks]]`).

> [!info] איך לנווט
> כל תת-תיקייה כאן ממפה אזור אחד בפרויקט ויש בה `_index.md` משלה. התחל מהאינדקס של האזור שמעניין אותך.

## אזורים

- [[root-config-index]] — קבצי תצורה בשורש הפרויקט (CLAUDE.md, env, gitignore)
- [[agents-index]] — הגדרות שלושת הסוכנים (חן, יעל, יובל)
- [[custom-skills-index]] — סקילים מותאמים לצוות (gpt-image-gen, obsidian)
- [[bundled-skills-index]] — סקילי Superpowers המובְנים (קוד צד-שלישי)
- [[content-index]] — מאמרי גלם ומקורות שממתינים לעיבוד
- [[output-index]] — תוצרים סופיים של יעל
- [[chen-workspace-index]] — סביבת העבודה והזיכרון של חן
- [[yael-workspace-index]] — סביבת העבודה וסגנון הבית של יעל
- [[yuval-workspace-index]] — סביבת העבודה והתמונות של יובל
- [[rachel-workspace-index]] — סביבת העבודה של רחל (Planning_Data / Planning_Output)
- [[obsidian-config-index]] — קבצי תצורה של אפליקציית Obsidian
