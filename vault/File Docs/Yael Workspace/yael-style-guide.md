# style-guide.md — מדריך סגנון הבית

**נתיב:** `yael/style-guide.md`

## מה הקובץ עושה
מדריך סגנון הבית שיעל קוראת בתחילת כל סשן ומשכתבת לפיו. כרגע **שלד למילוי** עם סקשנים: טון וקול, גוף ושפה, מבנה המאמר, מילים וביטויים, מה תמיד/אף פעם לא עושים, דוגמאות. ככל שימולא בפירוט — השכתוב של יעל יתקרב יותר לסגנון הרצוי.
