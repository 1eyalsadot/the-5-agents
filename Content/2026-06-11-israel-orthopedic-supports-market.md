## 6. רגולציה

### ישראל — אמ"ר (אביזרים ומכשירים רפואיים), משרד הבריאות
מקורות: Emergo by UL, Arazy Group, Gov.il.
- **הרגולטור:** אגף האביזרים והמכשור הרפואי (אמ"ר / AMAR) במשרד הבריאות.
- **סיווג:** לישראל **אין שיטת סיווג עצמאית** — היא מאמצת את סיווג ה-**FDA האמריקאי / CE האירופי / אוסטרליה / קנדה**. סיווג מבוסס-סיכון: **Class I / II / III**. תומכות/בריאסינג רבים = Class I (סיכון נמוך).
- **הכרה ב-CE/FDA:** רישום בישראל **מבוסס על אישור מוקדם** באחד מ"שווקי הייחוס" (אוסטרליה/קנדה/אירופה/ארה"ב). מוצר עם CE או FDA כבר מחזיק את עיקר התיק הנדרש.
- **מסלול מקוצר (אוג' 2023):** הוצג מסלול **הצהרה עצמית** (self-declaration) למוצרי Class I בסיכון נמוך שכבר רשומים ומשווקים במדינה מוכרת — חידוש שנתי. מקל מאוד על מוצרי soft goods.
- **לוחות זמנים:** ~120 ימי עבודה לרישום סטנדרטי; מסלולים מהירים לחלק מהקטגוריות.

### גלובלי — MDR/CE/FDA
- **EU MDR** (Medical Device Regulation) — נדרש CE לשיווק באירופה; רוב התומכות = Class I.
- **FDA** — רוב הבריאסינג/supports = Class I, פטור 510(k) ברבים מהמקרים (general controls).
- אוריאל מצהירה על עמידה ב-MDR/CE/FDA (לפי הבריף של ראובן; באתר הרשמי שנקרא צוין רק "ספק מורשה משרד הביטחון" — **המלצה: לאמת את אישורי ה-CE/FDA/MDR ישירות מול דף תאימות/תעודות של החברה לפני פרסום**).
